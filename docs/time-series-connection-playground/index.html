Kết nối thử dữ liệu chuỗi thời gian

Tạo kết nối, duyệt metric hoặc measurement, rồi xem dữ liệu trả về từ API ngay tại đây.

Lưu ý: Tạo kết nối sẽ lưu connector vào project. Preview chỉ đọc và không tạo dataset. Sau khi thử, có thể xóa kết nối ngay tại đây.

Nguồn dữ liệu

Loại nguồn dữ liệu

Bao gồm prefix `/api/v1`. Cookie phiên được gửi kèm tự động.

API bên ngoài máy này. Chỉ tiếp tục nếu đây là backend bạn tin cậy. API này sẽ nhận request tạo kết nối và secret.

Phiên đăng nhập cần có quyền Project Manager hoặc Researcher để tạo kết nối.

Dùng URL gốc, không thêm `/api/v1`. Demo public không cần xác thực.

Nguồn dùng HTTP, không mã hóa. Token hoặc username/password sẽ đi từ backend tới nguồn qua kết nối không mã hóa. Chỉ dùng trên mạng bạn tin cậy.

Để trống cả hai với demo Prometheus public. Token được xóa khỏi ô nhập sau khi tạo kết nối thành công.

Dùng token cho InfluxDB 2/3 hoặc username/password cho InfluxDB 1.8.

Đăng nhập trên frontend trước, rồi nhập Project ID để bắt đầu.
